## 修复

- `sapper_tools` 在受管会话中同时列出父会话允许、且符合角色工具范围的本地工具和 MCP 工具。reason 查阅探索角色目录，仍没有执行外部工具或创建图节点的权限。
- 搜索按各关键词命中数排序，精确工具名优先；status 明确显示当前角色、目录角色和可用工具。空搜索结果不再被描述为没有执行能力。
- 每次规划直接附上探索工具目录。提示词明确：上传附件已是合法输入事实，应先规划检查内容及本机解包程序；缺少专用解包 MCP 不构成拒绝本地命令路线的理由。列出命令工具不表示预装了某个 RAR 解包器，需要实际检查。
- 结构化规划允许 `blocked_reason`；无计划但有具体阻塞时记录 `SAPPER_PLANNING_BLOCKED`。尚未开展探索就空计划结束时记为 `SAPPER_PLANNING_EMPTY`，状态为 failed，目标保持未完成。
- 主会话结果包含运行级错误，即使没有 outcome 也保留明确原因。该任务可继续产生下一轮，不重建工作区、不覆盖旧 r001。

默认 MCP 工作流独占、最终权限检查、候选即时回显、多 flag 和可选复核保持有效。
